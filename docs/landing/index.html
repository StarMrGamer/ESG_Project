A second opinion on every ESG rating in ASEAN.

A rating is a level — where a company stood, in a file closed months ago. It does not tell you which way that company is moving, or what would change the answer. So we rank all 52 companies in the ASEAN ESG-momentum basket twice: once on their published score, once on dated public evidence. Then we report the gap.

It never says buy, sell or hold, and it never issues a score of its own. It says where it disagrees with a rating, shows you every dated source underneath, and tells you which one, if it vanished, would change its mind.

How the second rank is built

The model reads. The rules score. Nothing in between.

A language model is good at finding a fact in a page and terrible at deciding what it is worth. So it is only ever allowed to do the first job. It never sets a direction, a confidence or a label — those come from arithmetic that any reviewer can read.

01 / GATHER

Up to 27 searches per company

Four angles — emissions, governance, financing and controversies — aimed in turn at regulators, exchanges, rating houses and watchdogs, then repeated back across past years. The fourth angle is deliberate: without it, a sweep quietly becomes a press-release collection.

02 / GRADE

A fact with no date is dropped

So is a source URL the search never actually returned — the model cannot cite what it was not shown. Source type is decided by the domain, by us, so a publisher can never grade itself. Anything we cannot place is treated as the company's own voice, the cheapest grade there is.

03 / SCORE

Rules route it, arithmetic scores it

Direction, materiality and confidence are all rule-derived, with company-published sources capped at half weight and forward-looking promises halved again. No clock, no randomness, no model. Same files in, same run id out.

04 / COMPARE

Rank twice, then subtract

Percentile on the evidence, percentile on the published score, and the signed difference between them. That difference is the entire output. It is not a rating, and it cannot be read as one.

What it will not do

The limits are on the page, because that is the whole product.

A tool whose argument is that inconvenient evidence must surface cannot make an exception for its own.

It will not lower its own bar
We published, in advance, the single reason that would justify moving the hidden-winner threshold — before the evidence that would be judged against it existed. Then we gathered better sources, and four names crossed on their own. The bar never moved. A quadrant filled by relaxing the test would only ever mean we found a lot of press releases.
It will not trust a company about itself
Roughly 86% of what a public search returns is written by the companies themselves, so confidence is capped at half for that grade and cannot climb past it however much of it we gather. Four hidden winners is what survives the cap. The honest route to a longer list is better sources — regulator actions, exchange filings, index decisions — not a smaller number.
It will not quote only its good backtest
The foundation basket beat its index 55.1% to 6.4% across 2019–2023. The same research note has it lagging by 4.6% year-to-date, and finds that ESG improvement alone does not predict single-stock performance. Both numbers travel together here, or neither does.
It will not oversell the chain
Each run hashes its evidence into one Merkle root and anchors it, append-only. That is a receipt, not a check. A chain cannot verify an off-chain fact, and immutability applied to a false claim only makes the false claim permanent. Verification happens off-chain, in rules you can read. No token, no on-chain scoring, no licensed data ever written.
It will not claim a sensor it does not have
We read filings, regulator actions, exchange notices and press. We do not meter a smokestack. That is a real limit on what this can currently see, and the route past it is alternative data, not a stronger adjective.

The basket

52 ASEAN companies with consistent ESG-score improvement 2019–2023, from CGS International's published strategy note, 29 Aug 2025. Two constituents have since delisted and are marked.

The incumbent view

Each company's published ESG score as carried in that note, percentile-ranked against the same 52. The note's own column is unattributed, so it travels here unattributed and is never presented as any named agency's rating.

The industry bar

Greenhouse-gas intensity per euro of gross value added, Eurostat env_ac_aeint_r2, EU-27, 2023 — reproducible from a free, keyless API. It sizes an industry's structural footprint and is never differenced against a company score.

Reproducing this page

Every figure comes from run 1fc384a2fa92499d. The engine takes no clock, no randomness and no network, so the same input files rebuild the same run id and the same records on any machine.

This is a research prototype built for the PolyFinTech100 Category Finals. It reports disagreements between dated public evidence and published ESG scores. It is not investment advice, it does not recommend buying, selling or holding any security, and it does not issue an ESG score of its own. Company names and third-party data are referenced for research and attribution only.
